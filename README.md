# Algorea Pseudo Code

The web version of the Algorea Pseudo Code app: contest-style algorithm problems to solve on
paper in pseudo-code, with step-by-step animations, in French, English and Vietnamese.

Open it at https://bunyu.github.io/algo_pseudo/ — a shared problem opens at
`#<question id>`. Progress stays in the browser.

This repository is generated: `index.html` is built from the Algoréa trainer project
(`python tools/publish_web.py`). Do not edit it here.
